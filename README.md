# honeypot-eval

A small, open scheming honeypot evaluation built in [Inspect](https://inspect.aisi.org.uk/), after Krakovna et al. (2026), "Realistic honeypot evaluations for scheming propensity".

Work in progress. Design notes are in [DECISIONS.md](DECISIONS.md).

## Setup

```bash
uv sync
cp .env.example .env   # then add your OPENROUTER_API_KEY
```

Agentic tasks need Docker running.
